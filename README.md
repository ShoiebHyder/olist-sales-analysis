# Olist E-Commerce Sales Analysis

SQL and Power BI analysis of Brazilian e-commerce orders.

## Dataset
[Brazilian E-Commerce Public Dataset by Olist (Kaggle)](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
9 tables, about 100k orders from 2016-2018. The raw CSVs are not included in this repo because of their size.

## Tools
- PostgreSQL / pgAdmin
- SQL
- Power BI

## Project Structure
- `01_create_tables.sql`: creates the 9 tables
